# US-001: License Plate Recognition via OCR

**As a:** System user  
**I want:** The system to recognize the characters of vehicle license plates in images  
**So that:** I can get the plain text of the plate and process it automatically  

## Acceptance Criteria

| Scenario | Given | When | Then |
|----------|-------|------|------|
| **Successful Recognition** | The system receives a clear image with a visible license plate | The OCR module processes the image | The system correctly returns the plain text of the license plate (e.g. "AB123CD") |
| **No License Plate Detected** | An image that contains no license plate is provided | The OCR module tries to process it | The system returns a message indicating that no license plate was detected |
| **Low Quality Image** | A blurry or dark image, or one with an obstructed license plate, is provided | The OCR module tries to read the characters | The system returns a read error or a low confidence level, asking for a new image |
| **Text Extraction** | A valid license plate has been detected | The recognition process finishes | The result is made available exclusively as plain text without odd special characters |
